Forge versions links

## forge-versions.json

JSON containing links to the recommended (or latest, if no recommended build exists) [Minecraft Forge](https://files.minecraftforge.net/) installer jar for every supported Minecraft version.

> [!NOTE]
> This file is updated automatically every 3 hours by a GitHub Actions workflow.
> Generator: [cemyilmazzzz122/minecraft-version-links](https://github.com/cemyilmazzzz122/minecraft-version-links/tree/master/forge)
>
> Format follows [osipxd/Paper versions links](https://gist.github.com/osipxd/6119732e30059241c2192c4a8d2218d9),
> with each version entry carrying its own `forge` build number alongside the `url`.
> Links point to the Forge **installer** jar (run it to produce a server), since Forge does not publish a
> ready-to-run server jar directly like Paper/Folia do.
